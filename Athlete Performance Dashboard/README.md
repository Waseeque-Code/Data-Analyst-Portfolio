## 📋 Project Overview

A comprehensive Athlete Performace dashboard analyzing **120+ years** of historical data (1896-2016). This project provides deep insights into athlete demographics, country performance, medal distribution, and historical trends across both Summer and Winter Olympics.

## 🔍 Key Insights

### 🏆 Country Dominance
- **United States** leads with **18,604** total medals — 2.5x more than second place
- **USA** also tops gold medals with **2,638**

### 👶 Age Factor
- **18-25 age group** secured **150,782 medals** (68% of total)
- Average athlete age: **25.45 years**

### 👩 Women in Olympics
- Female participation grew from **33** (1900) to **6,223** (2016)
- **18,800%** increase over 116 years

### 🏅 Medal Distribution
| Medal Type | Count | Percentage |

| Gold | 13,369 | 33.6% |
