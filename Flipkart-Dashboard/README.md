# 📊 Flipkart E-commerce Power BI Dashboard

## Dataset
E-commerce India Dataset (Kaggle)

## Visuals Used
- Cards (Total Sales, Profit, Quantity, Orders)
- Bar Chart (Category & Sub-Category wise Sales)
- Line Chart (Monthly Sales Trend)
- Slicers (State, Category, City, Sub-Category)

## Tools
Power BI Desktop
