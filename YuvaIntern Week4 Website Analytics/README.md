# Website Analytics and Conversion Rate Optimization

## 📌 Overview
This repository contains my submission for **Week 4 Task** of the **Retail eCommerce Data Analyst Internship** at **YuvaIntern**.

## 📝 Task Objective
To evaluate the effectiveness of an eCommerce website by analyzing digital metrics and suggesting actionable strategies to improve conversion rates.

## 🎯 Key Highlights
- **KPIs Analyzed:** Bounce Rate, Session Duration, CTR, Conversion Rate, Cart Abandonment, Pages per Session, Exit Rate
- **Analysis Framework:** 5-Stage Conversion Funnel (Awareness → Interest → Desire → Action → Retention)
- **Simulated Data:** Current performance vs Industry benchmarks with gap analysis
- **High-Impact Areas:** Bounce Rate, Cart Abandonment, Checkout Optimization, Mobile UX
- **Visualizations:** Funnel Chart, Bar Chart, Line Chart, Heatmap
- **Recommendations:** A/B Testing, Checkout Streamlining, Personalization, Mobile-First, Cart Retargeting
