# Zomato Data Analysis📊

## Dataset
- **Source:** Kaggle - Zomato Restaurant Reviews
- **File:** reviews.csv (775 rows × 7 columns)
- **Columns:** Index, Name, Overall_Rating, Cuisine, Rate for two, City, Review

## Tasks Completed
✅ Data Loading  
✅ Data Cleaning (missing values, duplicates)  
✅ Basic Statistics  
✅ Visualizations (3 plots)  

## Key Insights
- Average Rating: 3.78
- Top City:  bangalore
- Most Popular Cuisine: Cafe, Fast Food
- Average Cost for Two: ₹631.33

## Files
- `zomato.py` - Main analysis script
- `rating_distribution.png` - Rating distribution plot
- `top_cities.png` - Top 10 cities chart
- `price_vs_rating.png` - Price vs Rating scatter plot

## Tools Used
- Python 3.x
- Pandas, NumPy, Matplotlib, Seaborn
