# 🏥 RSHCE Foundation - Sales Analytics Dashboard

## 📌 Project Overview
This dashboard was developed during my internship at **RSHCE Foundation** to analyze sales performance across Delhi NCR region. The project involved data cleaning, exploratory analysis, and interactive dashboard creation using **Microsoft Excel**.

## 🎯 Key Features
- **Sales Analysis:** Total sales of ₹47.33 Cr with monthly trends
- **Regional Breakdown:** Performance across 9 regions (Noida, Delhi, Gurugram, etc.)
- **Category Analysis:** Electronics, Furniture, Home & Kitchen top categories
- **Sales Rep Performance:** Individual rep tracking and ranking
- **Key Metrics:** Total orders (30,000), Profit (₹14.90 Cr), Avg Rating (4.22)

2. Open in Microsoft Excel (2016 or later)
3. Use slicers to filter by Region, Category, Quarter
