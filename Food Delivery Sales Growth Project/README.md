# 🍔 Food Delivery Sales Growth Analysis

## 📌 Problem
A food delivery platform wants to **increase sales by 20% in 3 months** using existing customer base and operational improvements.

## 🎯 Key Findings
- **₹2.38L lost** due to order cancellations (13.35% cancellation rate)
- **₹82.5K wasted** on ineffective promos (₹15 discount → ₹0 extra sales)
- **Premium customers spend 11.6% more** per order (₹128.50 vs ₹115.19)

## 📊 Tools Used
- **SQL** (MySQL) for data analysis
- **Excel / Power Query** for data cleaning
- **PDF** for final reporting

## 🔍 Key SQL Queries
- Cancellation impact analysis
- Promo effectiveness
- Premium vs non-premium AOV
- Monthly sales trend
- Delivery delay impact

## 💡 Top 3 Recommendations
| Action | Expected Impact | Effort |
|--------|----------------|--------|
| Reduce cancellations (2-min policy) | ₹1.19L | Low |
| Fix promo strategy (orders > ₹200) | ₹41K (cost saving) | Low |
| Improve delivery time (real-time ETA) | ₹77K | Medium |

**Total expected: ₹3.08L (86% of 20% target)**
