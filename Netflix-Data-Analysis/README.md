# Netflix Content Analysis 📊

## 📌 Project Overview
This project is a Python-based exploratory data analysis (EDA) of Netflix’s content library.  
The goal is to practice real-world data analyst thinking by analyzing content strategy, audience targeting, and regional trends using a public CSV dataset.

This project is part of my **data analytics learning journey** and focuses on solving practical business-style questions.

---

## 🎯 Learning Objectives
- Practice data cleaning and data quality checks
- Perform exploratory data analysis using Python
- Answer real-world business questions using data
- Improve storytelling through insights and visualizations

---

## 📂 Dataset Information
- **Dataset:** Netflix Titles Dataset
- **Format:** CSV
- **Records:** ~8,800
- **Important Columns:**  
  `title`, `type`, `country`, `date_added`, `release_year`,  
  `rating`, `duration`, `listed_in`, `director`, `cast`

---

## 🛠️ Tools & Technologies Used
- Python (Pandas, NumPy)
- Matplotlib & Seaborn
- Jupyter Notebook
- GitHub

---

## 🔍 Analysis Breakdown

### 1️⃣ Data Quality & Exploration
- Missing value analysis and patterns
- Duplicate record checks
- Handling missing values in important columns
- Detection of invalid dates and durations

---

### 2️⃣ Content Strategy Analysis
- Movies vs TV Shows distribution
- Year-wise content addition trends
- Country-wise content growth (India, Korea, UK, etc.)
- Time gap between release year and Netflix addition

---

### 3️⃣ Audience & Genre Analysis
- Content rating distribution (Kids vs Adult)
- Popular genres and trend changes over time
- Region-specific genre analysis (India-focused study)

---

### 4️⃣ Advanced Insights (Practice Level)
- Content freshness analysis
- US vs non-US content comparison
- Single-season vs multi-season TV shows
- Identification of underrepresented genres and regions

---

## 📈 Key Observations
- TV Shows have increased over the years, indicating a focus on long-form content.
- International content growth is visible, especially from India and Korea.
- Drama and Comedy are the most common genres on Netflix.
- Most content is added within a few years of its original release.
