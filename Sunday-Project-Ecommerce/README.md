# 🛒 E-Commerce Sales Analysis

## 🎯 Project Goal
Analyze 1,000+ e-commerce orders to uncover revenue drivers, customer behavior, and operational inefficiencies.

## 🛠️ Tools Used
- **Excel** - Data cleaning (removed duplicates, fixed date formats, standardized text)
- **MySQL** - Advanced analytics (window functions, CTEs, aggregation)
- **Power BI / Tableau** - Interactive dashboard
