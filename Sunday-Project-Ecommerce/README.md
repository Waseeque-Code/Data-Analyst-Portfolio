# 🛒 E-Commerce Sales Analysis

## Project Overview
Analyzed 1,439 e-commerce orders worth $1.09M+ to find revenue drivers and customer behavior.

## Key Metrics
- **Total Revenue:** $1,089,000+
- **Total Orders:** 1,439
- **Avg Order Value:** ~$756

## Key Insights
- **Top Category:** Electronics ($167,404)
- **Peak Month:** December 2024 ($52,875) - 16.4% above average
- **Top Customer:** Emily Smith ($5,984)
- **Highest Cancellation:** Cash on Delivery (28.22%)

## Business Recommendation
Offer 5% discount on prepaid orders to reduce Cash on Delivery cancellations.

## Tools Used
- Excel (Data Cleaning)

- Power BI (Dashboard)
