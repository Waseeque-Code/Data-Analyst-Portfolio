# Customer Behavior Analysis and Segmentation Strategy

## 📌 Overview
This repository contains my submission for **Week 2 Task** of the **Retail eCommerce Data Analyst Internship** at **YuvaIntern**.

## 📝 Task Objective
To explore customer data analytics by creating a segmented analysis of different customer groups for an eCommerce platform, using publicly available examples and theories to simulate the process of customer segmentation and behavioral analysis.

## 🎯 Key Highlights
- **Segmentation Methodology:** RFM Analysis (Recency, Frequency, Monetary) + Behavioral + Demographic criteria
- **5 Customer Segments:** High-Value Loyalists, Occasional Shoppers, Window Shoppers, New Customers, Dormant Customers
- **Simulated Data Matrix:** % of Customers, Revenue Contribution, AOV, Retention Rate, Purchase Frequency
- **Key Insight:** 12% customers (High-Value Loyalists) generate 42% of total revenue
- **Marketing Strategies:** Segment-wise recommendations for retention, conversion, and reactivation
