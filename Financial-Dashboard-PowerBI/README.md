# Financial Performance Dashboard 📊

## Overview
Interactive Financial Dashboard built using Power BI
on Company Financials dataset from Kaggle.

## KPIs
- Total Revenue: $118.73M
- Total Expenses: $101.83M
- Total Profit: $16.89M
- Profit Margin: 16.59%

## Features
- Interactive filters (Year, Quarter, Product, Segment, Country)
- Profit trend by Month
- Revenue vs Expenses by Quarter
- Product-wise Profit breakdown
- Drill-through detail table

## Tools Used
- Power BI Desktop
- DAX Measures
- Power Query

## Dataset
Company Financial Dataset — Kaggle
