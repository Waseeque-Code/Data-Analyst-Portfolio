# 🛒 E-Commerce Retail EDA

## Overview
Full exploratory data analysis on 2 years of UK e-commerce 
transactions (Dec 2009 – Dec 2011).

## Key Metrics
- 💰 Total Revenue: £17,374,804
- 📦 Total Orders: 36,975
- 👥 Total Customers: 5,881
- 🌍 Countries: 41

## What's Inside
- Data Cleaning (nulls, cancellations, outliers)
- Product Analysis (top sellers, revenue)
- Customer Segmentation (RFM Analysis)
- Time Trend Analysis (monthly, yearly, day-of-week)
- 10+ Visualizations

## Tools Used
Python | Pandas | NumPy | Matplotlib | Seaborn

## Dataset
UCI Online Retail II — [Kaggle Link](https://www.kaggle.com/datasets/mashlyn/online-retail-ii-uci)
