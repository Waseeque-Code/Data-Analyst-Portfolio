# Evaluating Pricing Strategies Through A/B Testing

## 📌 Overview
This repository contains my submission for **Week 5 Task** of the **Retail eCommerce Data Analyst Internship** at **YuvaIntern**.

## 📝 Task Objective
To critically analyze pricing strategies using A/B testing methodologies tailored for an eCommerce setting.

## 🎯 Key Highlights
- **Pricing Strategies:** Discount, Premium, Dynamic, Psychological, Bundle Pricing
- **A/B Testing Framework:** Control vs Test Groups with 3 Hypotheses (H1, H2, H3)
- **Statistical Methods:** Two-Sample T-Test, Chi-Square Test, P-Value (p < 0.05)
- **Simulated Results:** 4 Variants (Control, Bundle, Psychological, Discount) with Conversion Rate, AOV, RPV, Cart Abandonment
- **Key Insight:** Bundle Pricing highest RPV ($1.98), Discount Pricing highest Conversion (3.10%)
- **Recommendation:** Hybrid Model — Bundle + Psychological Pricing
