# 🌾 Agribusiness Financial Data Analysis

## 📌 Project Overview
This project is part of my internship at **YuwaIntern** as a **Financial Data Analyst - Agribusiness**.  
The goal is to source, clean, and analyze publicly available agribusiness financial data.

---

## 📊 Week 1: Data Sourcing & Preliminary Analysis

### ✅ What I Did
- Researched publicly available agribusiness data sources
- Selected 3 key sources: FAO, USDA ERS, FINBIN
- Downloaded FAO's "Value of Agricultural Production" dataset
- Filtered data for **India**
- Used only **"Gross Production Value (current thousand US$)"**
- Analyzed top agricultural commodities by financial value

### 📁 Data Source
- **FAOSTAT** — Value of Agricultural Production
- 3.39 million rows | 13 columns | 1961–2024

### 🛠️ Tools Used
- **Python** — Pandas, NumPy
- **VS Code** — Development environment
- **Git & GitHub** — Version control

### 📈 Key Insights
- India's total agricultural value: **8.81 Billion USD**
- Crops: **6.41 Billion** | Livestock: **2.39 Billion**
- Top commodities:
  - Vegetables & Fruits: **1.89B**
  - Total Milk: **1.83B**
  - Rice: **1.72B**
  - Buffalo Milk: **1.02B**
